# Reproducing the paper

The commands below recompute statistics from the supplied, unrounded per-case Dice scores. They do not read the reference CSVs. The [reference outputs](reference_results/) were generated by these commands and checked against the final paper's tables; values are stored before display rounding.

Install the pinned environment in the [quick start](README.md#quick-start), then run from the repository root. On Debian/Ubuntu, install the matching `python3-venv` package if environment creation reports that `ensurepip` is unavailable. All calculations run on CPU. The 2,000-draw commands take a few minutes, depending on the machine.

## Commands and reference outputs

```bash
mkdir -p results
python3 correlation.py --analysis all --output results/correlations.csv
python3 correlation.py --analysis primary --bootstrap 2000 --hierarchical --output results/primary_intervals.csv
python3 correlation.py --analysis primary --bootstrap 2000 --unit case --output results/primary_case_intervals.csv
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python3 effective_size.py --bootstrap 2000 --output results/effective_size.csv
python3 effective_size.py --analysis fixed --output results/fixed_threshold.csv
python3 pool_selection.py --output results/pool_selection.csv
python3 sensitivity.py --analysis all --output results/sensitivity.csv
python3 control_comparisons.py --analysis all --bootstrap 2000 --output results/control_comparisons.csv
python3 correlation.py --analysis controls --bootstrap 2000 --output results/control_intervals.csv
for analysis in mask_align per_rater kvasir_grouped medical_encoders amos heldout pixel_overlap; do
  python3 extensions.py --analysis $analysis --bootstrap 2000 --output results/$analysis.csv
done
for analysis in bundle_dice failure_metrics failure_intervals calibration item_difficulty tau_sweep \
    vit_diagnostic checkpoints unet_nine pipeline_metrics hierarchy; do
  python3 diagnostics.py --analysis $analysis --intervals --output results/$analysis.csv
done
```

Each output has a corresponding file with the same name under `reference_results/`. `--output` is optional; without it, the scripts print CSV to stdout. Correlation, effective-size, control-comparison and extension commands default to point estimates unless `--bootstrap` is supplied; `diagnostics.py` adds its intervals with `--intervals`, which uses each statistic's recorded draw count and seed (listed in the output). The fixed-threshold and sensitivity analyses provide point estimates only.

## Values outside this release

Only the following printed values cannot be recomputed from the released files.

- **Phikon-derived.** Phikon outputs are not included: Owkin's licence permits sharing only for non-commercial use by non-profit organisations and excludes transfer to for-profit organisations, which a public repository cannot ensure. Values that pool Phikon with other encoders therefore cannot be recomputed exactly, and no substitute without Phikon is given, because the paper does not report one: all of Table H.1, the Phikon and pooled-medical rows of Table H.2, the two medical-encoder rows of Table C.5, and the pooled-medical and extended-pool values in Section 6 and Appendices G.3 and H. The primary references they cite are reproduced.
- **Mask- or image-derived.** The mask-centroid offset and its 1,808-slice count in Appendix B.3; the rater mask with an open disc rim in Appendix B.1; and the image panels and area-based case selection of Figures 4 and C.1.
- **Run-log-derived.** The GPU-hours, GPU count and GPU model in Table B.3.
- **Other.** The ISIC Archive patient and lesion counts in Appendix I.1 come from external ISIC metadata, and the MSD Hippocampus volume and subject counts from the dataset description. The UNet-skip decoder parameter counts in Appendix G.1 follow from the decoder code in [`code/`](code/README.md), not from scores.

## Protocol details that affect the numbers

**Alignment and filtering.** `scores.py` checks case identities, clusters, model/seed rosters and metadata. The default quality screen keeps all heads of bundles whose mean Dice over heads and cases is at least 0.30. Floors are fixed before resampling. Pearson correlations with a trace standard deviation below `1e-8` are undefined; pair means use finite pairs. Invalid bootstrap draws are counted and omitted from percentile calculations.

**Primary and hierarchical intervals.** Table 2's primary intervals resample images for Kvasir/RIGA and patients with all associated slices for ACDC/BraTS, using seed 0 and 2,000 draws. `--unit case` reproduces the separate case-bootstrap column. Hierarchical sensitivity merges DINOv2-B/S into one release group, resamples observed groups and heads within each occurrence, and shares case/patient draws across all heads. Duplicate head draws retain self-correlations; pairs between separate occurrences of the same group are excluded. Its percentiles describe the observed panel, not a population of model families.

**Effective size.** P33 is computed separately for each recipe after its quality screen and stays fixed during resampling. Every member needs at least five failures and five passes. Pool sizes are calculated before averaging; substituting an average correlation into the effective-size formula gives a different statistic. Table E.1(a) uses the fixed threshold 0.85 and separate positive-denominator checks for Eqs. (2) and (3). At P33, the exact-covariance output uses pools where both ratios are defined; these eligibility sets coincide for all supplied P33 panels.

**Fine-tuning comparisons.** Table G.3 uses the same sampled image indices for FT and frozen scores, with seed 0. Table G.4 also pairs image draws but fixes each recipe's own P33. Its paired frozen marginal is returned in the FT rows; for RIGA Cup it differs slightly from Table E.1(b)'s frozen CI because the original bootstrap streams differ. Table E.1 uses task offsets of 100,000 in the listed primary-task order; Table G.4 uses seed 0. Valid draw counts and seeds are recorded in the CSVs.

**nnU-Net.** Table G.5's Dice/correlation summaries use all ten members (five folds × seeds 13 and 37). Its effective size uses the five-fold pool at training seed 13 and that pool's P33. ACDC uses 100 ED/ES frame volumes from 50 patients; its bootstrap resamples patients. RIGA uses 95 images. The original effective-size bootstrap seeds are 1,120,000 and 1,020,000, respectively; fold-gap bootstrap uses seed 0.

**Selection.** The 200 calibration/evaluation splits per task use seeds 0–199. Calibration alone selects the four-family pool and threshold. The low-effective-size fraction is **910/1,400 = 65.0%**, including 61 unsupported splits in the denominator; the supported-only fraction is **910/1,339 = 68.0%**. These are fixed-cohort split frequencies. See [data protocol](data/README.md#protocol) for the distinct calibration-threshold rule and patient weighting.

The original study scorers give the same values on the released panels: `compute_paired_gap_difference.py`, run on trace folders written from `primary/<task>` and `mask_align/<task>`, reproduces Table B.2's retained K, both gaps and the paired differences with their intervals, and `code/stats/recompute_amos.py`, run on the released AMOS case scores, matches all 676 numeric fields of the study's AMOS output within 2.2e-16. Where the study stored its outputs, `diagnostics.py` matches them within 4e-15; its item-difficulty residuals use the closed-form residual covariance of the study's single-regressor least-squares fit.

Some appendix values came from the study's independent verification checks rather than from the scorers in `code/`: the patient-resampled intervals of Appendix D.1 and D.2, the RIGA Disc κ diagnostics of Appendix D.2, the hierarchical self-pair check of Appendix C.1, the residualised-gap permutation null of Appendix D.4, the no-floor column of Table D.1(a), Table F.2(b) and the two grouping-sensitivity gaps quoted in Section 5 (DINOv2-B×S pairs moved to the cross group). `sensitivity.py` and `diagnostics.py` reproduce them with those checks' rules and seeds; of the check scripts themselves, only [`compute_quality_controlled_cluster.py`](code/scripts/compute_quality_controlled_cluster.py) (the patient-resampled βsame intervals) is included.

The study implementation expects raw datasets, model weights and full result directories, which are not distributed; for the supplied scores, use the top-level commands. The score-pack provenance and access terms are in [data/README.md](data/README.md).

## Checks and scope

```bash
python3 -m unittest discover -s tests
sha256sum -c MANIFEST.sha256
```

The focused tests cover numerical edge cases, alignment failures, selected paper values (including point estimates of every extension table), the manifest and the Croissant file hashes. `sha256sum -c` checks the released data and reference outputs against [`MANIFEST.sha256`](MANIFEST.sha256). The full commands above reproduce the reference CSVs in the pinned environment (Python 3.10–3.12, NumPy 1.26.4, SciPy 1.15.3). Floating-point last bits can vary by platform; compare at the paper's displayed precision rather than requiring byte-identical CSVs.

The commands above start from saved Dice traces; they do not retrain models or regenerate traces from raw images. Training and inference code is in [`code/`](code/README.md) and needs the upstream datasets and models. Image and mask panels need inputs outside this package ([values outside this release](#values-outside-this-release)). No raw image/mask collection, prediction, feature cache, checkpoint, Phikon output or manuscript PDF is included.
